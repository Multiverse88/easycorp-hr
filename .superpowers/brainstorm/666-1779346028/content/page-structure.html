Struktur Halaman Website Rekrutmen

Apakah halaman-halaman ini sudah sesuai kebutuhan?

Internal (Login Required)
📋 Dashboard
Ringkasan semua request manpower, status interview, dan notifikasi terbaru
📝 Pengajuan Manpower
Form pengajuan kebutuhan tenaga kerja baru oleh departemen/HM. Bisa ditrack statusnya (pending → approved → open)
🎯 Hasil Interview
HR/interviewer input hasil interview per kandidat. Nilai, catatan, rekomendasi (lanjut/tidak)
🧠 Hasil Psikotes
HR input hasil psikotes kandidat. Nilai per aspek, kesimpulan, rekomendasi
👥 Manajemen Kandidat
List semua kandidat yang masuk, status proses rekrutmen, link ke hasil interview & psikotes
📊 Export & Laporan
Export data ke Excel / cetak PDF hasil interview & psikotes per kandidat
Eksternal (Kandidat — Akses via Link Unik)
📄 Form Biodata Kandidat
Kandidat isi data diri, riwayat pendidikan, pengalaman kerja via link unik yang dikirimkan HR
✅ Konfirmasi Jadwal
Kandidat konfirmasi kehadiran interview / psikotes
💡 Catatan
Kandidat eksternal tidak perlu login — akses via token unik di URL (contoh: /apply/abc123xyz). Link bisa diset expired setelah waktu tertentu.
